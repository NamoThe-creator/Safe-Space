# คู่มือเปิดเว็บเกม Safe Space • Campus Tycoon บน Cloudflare (ออนไลน์ 24 ชม. ฟรี)

แพ็กเกจนี้ได้รับการปรับปรุงจากซอร์สโค้ดต้นฉบับให้พร้อมขึ้นระบบ **Cloudflare Workers + D1** ทันที โดยไม่ต้องใช้เครื่องมือเฉพาะของระบบเดิม (`vinext` หรือ `pnpm@11.25.0`) และเมื่ออัปโหลดเสร็จแล้ว **ตัวเว็บจะออนไลน์ตลอด 24 ชั่วโมงบนเซิร์ฟเวอร์ของ Cloudflare โดยที่คุณสามารถปิดคอมพิวเตอร์ได้เลย**


## สิ่งที่เตรียมไว้ให้แล้วในชุดนี้

| ไฟล์ / โฟลเดอร์ | หน้าที่การทำงาน |
| :--- | :--- |
| `worker.js` | ระบบหลังบ้านสำหรับ Cloudflare Workers เชื่อมต่อฐานข้อมูล D1 จัดการสร้างห้องรหัส 6 หลัก, ล้างห้องหมดอายุอัตโนมัติ และขยายโควตาสร้างห้องเป็น 50 ห้องต่อเครื่องเพื่อรองรับการเปิดเล่นในห้องเรียน |
| `public/` | หน้าเว็บเกมฉบับคอมไพล์พร้อมใช้งาน (`index.html`, `app.js`, `styles.css`, ไอคอน และ PWA manifest) |
| `drizzle/0000_moaning_blade.sql` | คำสั่ง SQL สร้างตาราง `rooms` สำหรับเก็บสถานะห้องเล่นออนไลน์ |
| `wrangler.toml` | ไฟล์ตั้งค่า Cloudflare Workers และฐานข้อมูล D1 |
| `setup-and-deploy.mjs` | สคริปต์อัตโนมัติที่ช่วยล็อกอิน สร้างฐานข้อมูล D1 ผูก `database_id` สร้างตาราง และอัปโหลดเว็บขึ้นออนไลน์ในขั้นตอนเดียว |
| `deploy-windows.bat` / `deploy-mac-linux.sh` | ไฟล์สั่งรันสคริปต์อัตโนมัติสำหรับ Windows และ macOS / Linux |
| `src/` | ซอร์สโค้ดต้นฉบับภาษา TypeScript / React (`lib/game.ts`, `app/page.tsx`, `app/api/game/route.ts`) เผื่อต้องการแก้ไขเพิ่มเติมในอนาคต |


## สิ่งที่ต้องมีก่อนเริ่ม (ใช้แค่ครั้งแรกครั้งเดียว)

1. **ติดตั้งโปรแกรม Node.js** (แนะนำเวอร์ชัน 20 หรือ 22 LTS) ดาวน์โหลดได้ฟรีจาก [nodejs.org](https://nodejs.org/)
2. **สมัครบัญชี Cloudflare ฟรี** ที่ [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) (ใช้แผน Free ไม่เสียค่าใช้จ่าย)


## วิธีที่ 1: รันสคริปต์อัตโนมัติ (แนะนำ — ง่ายและเร็วที่สุด)

1. แตกไฟล์ `safe-space-cloudflare-ready.zip` ลงในโฟลเดอร์บนคอมพิวเตอร์ของคุณ
2. หากใช้ **Windows** ให้ดับเบิลคลิกไฟล์ `deploy-windows.bat` (หรือเปิด Terminal / Command Prompt ในโฟลเดอร์นี้แล้วพิมพ์คำสั่ง `node setup-and-deploy.mjs`)
3. หน้าต่างเบราว์เซอร์จะเด้งขึ้นมาเพื่อให้คุณล็อกอินบัญชี Cloudflare และกดปุ่ม **Allow** เพื่ออนุญาตให้เครื่องมือ Wrangler เชื่อมต่อบัญชี
4. หากเพิ่งใช้ Cloudflare Workers ครั้งแรก ระบบในเทอร์มินัลอาจถามชื่อ Subdomain ของคุณ ให้พิมพ์ชื่อที่ชอบแล้วกด Enter
5. สคริปต์จะดำเนินการให้อัตโนมัติครบทั้ง 4 ขั้นตอน:
   - สร้างฐานข้อมูล Cloudflare D1 ชื่อ `safe-space-db`
   - นำค่า `database_id` มาใส่ในไฟล์ `wrangler.toml` ให้อัตโนมัติ
   - สร้างตาราง `rooms` บนฐานข้อมูลออนไลน์
   - อัปโหลดหน้าเว็บและระบบหลังบ้านขึ้น Cloudflare
6. เมื่อเสร็จสิ้น หน้าจอจะแสดงลิงก์เว็บไซต์ของคุณในรูปแบบ:
   `https://safe-space-campus-tycoon.<ชื่อของคุณ>.workers.dev`
7. **คุณสามารถปิดคอมพิวเตอร์ได้เลย!** เว็บจะทำงานอยู่บนคลาวด์ของ Cloudflare ตลอด 24 ชั่วโมง


## วิธีที่ 2: พิมพ์คำสั่งทีละขั้นด้วยตัวเอง (กรณีต้องการทำผ่าน Terminal เอง)

หากต้องการรันคำสั่งทีละบรรทัดด้วยตัวเอง ให้เปิด Terminal หรือ PowerShell ในโฟลเดอร์ที่แตกไฟล์ไว้ แล้วรันตามลำดับนี้:

```bash
# 1. ล็อกอินเข้าบัญชี Cloudflare
npx wrangler login

# 2. สร้างฐานข้อมูล D1 ชื่อ safe-space-db
npx wrangler d1 create safe-space-db
```

หลังจากรันคำสั่งที่ 2 ระบบจะแสดงค่า `database_id` (รหัส UUID ยาวๆ เช่น `a1b2c3d4-...`) ให้นำรหัสนี้ไปใส่แทนที่ค่า `00000000-0000-4000-8000-000000000000` ในไฟล์ `wrangler.toml` บรรทัด `database_id = "..."` จากนั้นรันอีก 2 คำสั่ง:

```bash
# 3. สร้างตารางเก็บห้องเกมบนฐานข้อมูลออนไลน์
npx wrangler d1 execute safe-space-db --remote --file=./drizzle/0000_moaning_blade.sql

# 4. อัปโหลดเว็บขึ้นออนไลน์
npx wrangler deploy
```


## คำแนะนำสำหรับเปิดให้อาจารย์และเพื่อนเล่นพร้อมกันในคลาส

* **การแบ่งกลุ่มเล่นในห้องเรียน:** กติกาของเกมออกแบบให้เล่นได้ **2–4 คนต่อ 1 ห้อง** (กระดานมีหมาก 4 ตัว: 🦊 🐳 🐝 🐢)
* **เล่นพร้อมกันหลายกลุ่มได้ไม่จำกัด:** หากในคลาสมีเพื่อนและอาจารย์รวม 20–40 คน สามารถแบ่งเป็นกลุ่มละ 2–4 คน แล้วให้ตัวแทนแต่ละกลุ่มกดปุ่ม **"＋ สร้างห้องออนไลน์"** บนมือถือหรือโน้ตบุ๊กของตัวเองได้เลย ระบบจะสร้างรหัสห้อง 6 หลักแยกกันให้แต่ละกลุ่มเล่นไปพร้อมกันได้ทันทีโดยที่ข้อมูลไม่ปนกัน
* **เข้าผ่านมือถือได้ทันที:** นำลิงก์ `.workers.dev` ที่ได้ไปสร้างเป็น **QR Code** ขึ้นสไลด์หน้าห้องเรียน เพื่อนและอาจารย์สามารถสแกนเปิดเล่นผ่านเบราว์เซอร์บนมือถือ (Safari / Chrome) ได้ทันทีโดยไม่ต้องโหลดแอปใดๆ
